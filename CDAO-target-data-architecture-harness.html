Pre-decisional draft

Plain-English reading

The architecture builds trusted data products. The harness helps people and AI tools use those products with the right definitions, caveats, and answer expectations.

  • Data Management strengthens the product.
  • Data Analytics validates the interpretation.
  • The harness carries the shared context forward.

V1 pilot ask

Start with one small, reviewed playbook before building any app or middleware.

  • One data product or use case
  • One Data Management steward
  • One Data Analytics validator
  • One Confluence harness page
  • One 30-day usefulness review
